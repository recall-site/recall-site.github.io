What is RECALL

Contracts play an important role in business, and with electronic trading came the challenge of guaranteeing reliability between the parties. Automatically verifying multi-party contracts for conflicts is still a problem that few works have addressed.

RECALL is an automatic conflict checker for multi-party contracts modeled in the Relativized Contract Language (RCL). You describe each party's obligations, permissions and prohibitions, and the tool tells you whether there is any situation in which they contradict each other.

📝

Single analysis

Open an .rcl file or paste the contract into the editor. The editor includes a picker to insert language symbols.

📚

Batch analysis

Pick a folder and RECALL processes all contracts in parallel, producing a batch_results.csv summary.

🕸️

Automaton export

Export the contract automaton as .dot files (standard and/or minimal) to visualize with Graphviz.

📊

Metrics and logs

Each analysis reports time, automaton size and memory used, with quick access to the result, the full log and the table of symbols.

⚙️

Optimization and limits

Enable pruning for large contracts and tune the maximum number of concurrent relativized actions (default: 30).

🌗

Light and dark themes

A modern, lightweight interface that switches between light and dark themes.

Installation

On every system you just download and run the installer. On macOS there is one extra security step the first time you open the app.

🪟 Windows

  1. Download and run the .exe file (or the .msi).
  2. If SmartScreen warns about an unrecognized app, click More info and then Run anyway.
  3. Follow the wizard and launch RECALL from the Start menu.

🐧 Linux

Install the package for your distribution, or run the AppImage without installing:

# Debian / Ubuntu
sudo apt install ./recall_1.0.3_amd64.deb

# Fedora / RHEL
sudo dnf install ./recall-1.0.3-1.x86_64.rpm

# AppImage
chmod +x recall_1.0.3_amd64.AppImage
./recall_1.0.3_amd64.AppImage

🍎 macOS: opening the app for the first time

The app is not signed by Apple, so macOS blocks the first launch. Drag RECALL to the Applications folder, try to open it with a double click (the block message will appear), then allow it:

  1. Open System Settings.
  2. In the left sidebar, click Privacy & Security.
  3. Scroll down on the right side to the Security section.
  4. Below the "Allow applications downloaded from:" option, a message will tell you the app was blocked.
  5. Click the Open Anyway button.
  6. Enter your Mac password (or use Touch ID) to confirm.
System Settings › Privacy & Security › Security › Open Anyway

On older versions of macOS the layout is slightly different:

System Preferences › Security & Privacy › "General" tab › Open Anyway

Tip: the Open Anyway button only appears on that screen if you tried to open the app within the last 15 minutes. If more time has passed, double-click the app again and the option will come back in the settings.

How it works

RECALL implements the conflict detection algorithm proposed by Della Mura and Bonifácio. The contract written in RCL is parsed, turned into an automaton, and then analysed for conflicts in all the decompositions obtained.

  • Contract Representation: receives the contract in RCL and converts it into the internal structure to be processed.
  • Automaton Construction: builds the automaton that models the contract described in RCL.
  • Conflict Analysis: looks for conflicts in all decompositions obtained during the automaton construction.
  • Desktop Application: where the user provides the contract and the analysis settings and receives the result.

This version was rewritten from scratch in Rust with Tauri 2 and a React + TypeScript interface. The grammar parser uses pest and the analyser runs as a separate process (sidecar), which keeps the interface responsive even during heavy analyses. The result is a small, fast app that does not require a Java installation.
